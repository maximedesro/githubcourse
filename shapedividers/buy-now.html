What export formats can I use with Premium?

You can export a divider as CSS with embedded SVG, inline SVG markup or a reusable SVG mask. Gradient and animated designs can be generated from the same visual tool, and responsive settings can vary between desktop, tablet and mobile.

Can I change the colors after exporting?

Yes. Inline SVG exports can use CSS currentColor for solid colors, gradient SVG exports expose CSS variables for both colors, and SVG mask exports keep the visible color or gradient in CSS.
